## MrMAPI named-property output

`MrMAPI -NamedProps` lists store mappings with their mapped property tag, explicit `MNID_ID` or `MNID_STRING` kind, raw numeric ID or string name, and the property-set GUID plus its known symbolic name. Known numeric IDs also include all matching property names (for that GUID), without replacing the underlying ID. Unknown GUIDs/IDs remain visible; the command does not guess a property name from an ID in a different property set.

This is a human-readable diagnostic report, not a stable machine-readable schema. The existing named-property analysis and sort order are unchanged; enriched identities appear in both console and `-Output` reports.
